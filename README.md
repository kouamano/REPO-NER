# REPO-NER
## 名称定義
|対象|名称|
|----|----|
|トークンに相当する文字列のうちNamaed entityに相当するもの|Named entity / Entity|
|NERによりEntutyに付与されたラベル|NERラベル|
|ユーザーがまとめたEntityの並び|コンパウンド|
|コンパウンドに付与するラベル|クラスラベル|

## クラスラベルの種類
通常クラス
|対象|クラスラベル|
|----|----|
|史料・試料・資料・データ・ソースコード|res|
|ソフトウエア・試薬・実験キット・器具|tol|
|機材・設備・施設|fty|
|地域|NERラベルを使用|
|時代・時刻|tim|
|人名|NERラベルを使用|
|組織名|NERラベルを使用|
|上記以外|NERラベルを使用|

特別クラス：次に相当する場合は通常のクラスラベルに加えて以下のクラスラベルも付与する
|対象|特別クラス|
|----|----|
|当該論文の著者|au|
|当該論文の論文名|pub|
|当該論文著者の所属|ins|
