# REPO-NER
## 概要
PMC-NER https://github.com/kouamano/PMC-NER は、構造化文章からコンテンツテキスト部分を抜き出してNER処理するが、REPO-NERはPDF文章を対象とする。
まず、PDFから適切にコンテンツテキストを取り出す必要があるが、抽出後は基本的に PMC-NERと同じである。

また、NERの精度向上のため、一旦プログラムにNER判定させた結果を人がチェックし、必要に応じて修正した学習用（正解）データも作成する。この作業にはアルバイトを充てる予定である。さらに、アルバイト作業用のGUIも作成する。

## PDFからのテキスト抽出
まず、テキストおよびメタデータ（テキストブロック位置）を抽出する。
https://github.com/kouamano/REPO-NER/blob/main/%E3%83%86%E3%82%AD%E3%82%B9%E3%83%88%E6%8A%BD%E5%87%BA.md

次にメタデータをもとにテキストブロックを再構成する。
https://github.com/kouamano/REPO-NER/blob/main/textblock.nb

## 名称定義
|対象|名称|
|----|----|
|トークンに相当する文字列（ほぼ形態素に相当）|Word|
|トークンに相当する文字列のうちNamed entityに相当するもの|Named entity / Entity|
|NERによりEntityに付与されたラベル|NERラベル|
|ユーザーがまとめたEntityの並び|コンパウンド|
|コンパウンドに付与するラベル|クラスラベル|

NERラベルについては https://github.com/kouamano/PMC-NER を参照。

## クラスラベルの種類
通常クラス
|対象|説明|クラスラベル|
|----|----|----|
|史料・試料・資料・データ|研究の対象となるもの|res|
|ソフトウエア・試薬・実験キット・器具・機材|methodにかかわるごく一般的なツールなど。<br>例：PCRマシン（型番）、PCRキット（型番）、電子顕微鏡（型番）、LC/GC/MS（型番）、プログラム（リポジトリURL）|tol|
|設備・施設|methodにかかわるもののうち大型で複合的なもの。<br>例：船舶、天文台、人工衛星、加速器、放射光施設、ビームライン、スパコン、レンタルラボ、クラウドサービス等そのものに付与される名称|fty|
|地域||NERラベルを使用|
|時代・時刻||NERラベルを使用|
|人名||NERラベルを使用|
|組織名||NERラベルを使用|
|上記以外||NERラベルを使用|

特別クラス：次に相当する場合は通常のクラスラベルに加えて以下のクラスラベルも付与する
|対象|特別クラス|
|----|----|
|当該論文の著者|au|
|当該論文の論文名|pub|
|当該論文の著者所属|ins|
|当該論文の参考・参照リストにある論文等|ref|
|URL|url|
