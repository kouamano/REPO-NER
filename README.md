# REPO-NER
## 名称定義
|対象|名称|
|----|----|
|トークンに相当する文字列（ほぼ形態素に相当）|Word|
|トークンに相当する文字列のうちNamaed entityに相当するもの|Named entity / Entity|
|NERによりEntityに付与されたラベル|NERラベル|
|ユーザーがまとめたEntityの並び|コンパウンド|
|コンパウンドに付与するラベル|クラスラベル|

## クラスラベルの種類
通常クラス
|対象|説明|クラスラベル|
|----|----|----|
|史料・試料・資料・データ|研究の対象となるもの|res|
|ソフトウエア・試薬・実験キット・器具・機材|methodにかかわるごく一般的なツールなど<br>例：PCRマシン、PCRキット、電子顕微鏡、LC/GC/MS|tol|
|設備・施設|methodにかかわるもののうち大型で複合的なもの、量産型でないもの<br>例：加速器、放射光施設、ビームライン、スパコン|fty|
|地域||NERラベルを使用|
|時代・時刻||NERラベルを使用|
|人名||NERラベルを使用|
|組織名||NERラベルを使用|
|上記以外||NERラベルを使用|

特別クラス：次に相当する場合は通常のクラスラベルに加えて以下のクラスラベルも付与する
|対象|特別クラス|
|----|----|
|当該論文の著者|au|
|当該論文の論文名|pub|
|当該論文の著者所属|ins|
|当該論文の参考・参照リストにある論文等|ref|
|URL|url|
